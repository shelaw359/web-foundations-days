About QuickNotes

QuickNotes is a simple note-taking app that lets you write down ideas, reminders and to-dos in seconds. It keeps everything in one place so you can find and update your notes whenever you need them.

How to use QuickNotes

  1. Open the Home page and type your note into the note box.
  2. Click the Save button to store the note.
  3. Find your saved notes in the list on the Home page.
  4. Edit or delete a note whenever you need to.

Features

  • Create notes quickly
  • Edit and delete notes
  • Search through your notes
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
